Response to the technical check

Manuscript title: Evidence-weighted climatic coverage of public COI reference libraries: a framework applied to spider mites
Manuscript ID: 2e57974f-0aa8-4a65-98fe-3e818f09e55d v1.0
Authors: V. K. Chaudhari, Abhishek Shukla

**Point 1. The URL https://doi.org/10.15468/dl.xxfcra does not link to an existing or functional webpage.**

Checking this identifier showed that it is registered and resolvable, but that we had attached it to the wrong dataset in the manuscript. We have corrected that, and we are grateful for the check that brought it to light.

The identifier itself is a valid GBIF occurrence-download DOI. It is registered with DataCite in the "findable" state, registered on 31 October 2026, and resolves to the GBIF download record 0019101-261023074918325, which GBIF reports as a completed download of 4,706 records under a CC BY-NC 4.0 licence. The two companion identifiers in the manuscript, 10.15468/dl.aejp4w and 10.15468/dl.5mckab, are registered in the same state and resolve in the same way. We note that GBIF occurrence-download pages can return an error status to automated link checkers while opening normally in a browser, which may account for the result reported.

What was wrong is the attribution. In Methods, the identifiers for two of the three downloads had been transposed: 10.15468/dl.xxfcra was given for the *Tetranychus urticae* download and 10.15468/dl.5mckab for the *Oligonychus* download, when the reverse is the case. The record counts stated alongside them, 6,646 and 4,706, were correct throughout, as was the genus-level identifier for *Tetranychus*.

The sentence in Methods now reads:

Occurrence records were obtained from GBIF through the download API, which issues a citable DOI for a frozen snapshot, on 31 October 2026: *Tetranychus urticae* (6,646 records; doi:10.15468/dl.5mckab), *Tetranychus* at genus level (15,793 records; doi:10.15468/dl.aejp4w) and *Oligonychus* at genus level (4,706 records; doi:10.15468/dl.xxfcra).

Each identifier was verified against the GBIF download API before this response was written: 10.15468/dl.5mckab is taxon key 2130185, *Tetranychus urticae*, 6,646 records; 10.15468/dl.aejp4w is taxon key 2130777, *Tetranychus*, 15,793 records; and 10.15468/dl.xxfcra is taxon key 7871727, *Oligonychus*, 4,706 records. The list of the three downloads in the data availability statement is unordered and required no change.

No other part of the manuscript has been altered.
